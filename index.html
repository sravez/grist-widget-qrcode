Widget Grist QRLabel

Widget Grist de génération d'étiquettes organisées autour d'un QR code.

Exemple d'étiquette

Il est possible de personnaliser l'étiquette en choisissant :

  • les couleurs de premier plan et d'arrière-plan,
  • la taille de la bordure et du texte entourant le QR code.

L'orientation des textes et la taille de la quiet zone (zone vierge encadrant le QR code de même couleur que le fond) sont fixes.

Intégration dans votre document

Ajout d'un widget personnalisé

Ajouter le widget en ajoutant une vue personnalisée ; choisir le widget URL personnalisée et saisir l'URL suivante :

https://github.io/.../releases/latest

Autorisation d'accès

Pour profiter de toutes les fonctionnalités, il vous faut donner un accès complet du widget à la table sous-jacente.

Correspondance des champs/colonnes (Mapping)

Vous devez ensuite indiquer au widget les colonnes de votre table à utiliser.
ColonneTypeObligatoireDescription
label Pièce jointe Oui Image de l'étiquette
val Texte Oui Texte encodé dans le QR code
filename Texte Non Nom (sans extension) sous lequel sera enregistrée l'étiquette
top Texte Non Texte situé au-dessus du QR code
right Texte Non Texte situé à droite du QR code
bottom Texte Non Texte situé sous le QR code
left Texte Non Texte situé à gauche du QR code
validity Booléen Non Validité de l'étiquette déterminée par votre application
trigger Booléen Non Génération d'une nouvelle valeur pour val
editable Booléen Non Affichage de mise à jour des étiquettes

Colonne val

Texte (le plus souvent une URL) encodé dans le QR code.

Colonne filename

Nom (complété par .png) sous lequel sera enregistré le fichier graphique de l'étiquette.

En liant le nom de fichier et val, vous pouvez estimer la validité de l'étiquette et alimenter la colonne validity.

Colonnes top, right, bottom, left

Textes affichés sur chacun des côtés du QR code.

Colonne validity

Estimation par votre application de la validité de l'étiquette courante, basée par exemple sur le nom du fichier. Cela permet à utilisateur de filtrer sur cette colonne et de procéder à la génération d'une nouvelle étiquette.

Colonne trigger

Éventuelle colonne booléenne dont la mise à true génère une nouvelle valeur pour val.

Colonne editable

Si true, on affiche les boutons permettant d'enregistrer et d'actualiser l'étiquette.

Utilisation

Configuration

La configuration du widget est accessible via le volet latéral gauche. Elle permet de régler les paramètres suivants :
  • Affichage : taille des étiquettes et génération des visuels 
  • Données : position de l'étiquette courante et conservation de l'historique 
  • Étiquettes : tailles et couleurs 
  • Impression : mise en page des feuilles d'étiquettes.
Une aide détaillée est accessible pour chaque rubrique depuis la fenêtre de configuration.

Mise à jour

Si l'utilisateur dispose des droits, il lui est possible d'appliquer un nouveau visuel à l'étiquette courante ou à toutes les étiquettes correspondant au(x) filtre(s).

Il est en outre possible de donner la possibilité à l'utilisateur de rafraîchir l'étiquette via une colonne trigger qui peut modifier la valeur à encoder et mettre à jour les étiquettes. Cela peut être utile si on veut désactiver les étiquettes courantes si elles sont utilisées indûment.
